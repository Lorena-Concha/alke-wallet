# 💳 Alke Wallet

> Billetera digital desarrollada como proyecto final del Módulo 2 — Fundamentos del Desarrollo Front-End · Alkemy

---

## 🚀 Descripción

**Alke Wallet** es una aplicación web de billetera digital que permite a los usuarios gestionar sus activos financieros de manera segura y conveniente. Desarrollada con HTML, CSS, JavaScript, Bootstrap y jQuery.

---

## 📸 Pantallas

| Pantalla | Descripción |
|---|---|
| `login.html` | Inicio de sesión con validación de credenciales |
| `menu.html` | Dashboard con saldo, estadísticas y accesos rápidos |
| `deposit.html` | Depósito y retiro de fondos |
| `sendmoney.html` | Transferencias con búsqueda autocompletar de contactos |
| `transactions.html` | Historial completo con filtros, búsqueda y exportación |

---

## ⚙️ Tecnologías utilizadas

- **HTML5** — Estructura semántica
- **CSS3** — Estilos con variables CSS y diseño responsive
- **JavaScript (ES6+)** — Lógica de negocio, validaciones y manejo de datos
- **Bootstrap 5** — Componentes UI, navbar, modales y grid
- **jQuery 3.7** — Manipulación del DOM, autocompletar, animaciones y eventos

---

## 🎯 Funcionalidades

- ✅ Login con validación de email y contraseña
- ✅ Dashboard con saldo animado y estadísticas
- ✅ Depósito y retiro de fondos con montos rápidos
- ✅ Envío de dinero a contactos con autocompletar jQuery
- ✅ Agregar nuevos contactos
- ✅ Historial con filtros por tipo y categoría
- ✅ Búsqueda en tiempo real
- ✅ Paginación del historial
- ✅ Exportación a CSV
- ✅ Persistencia con localStorage y sessionStorage
- ✅ Diseño responsive (mobile-first)
